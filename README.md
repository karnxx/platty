# PLATTY
- speed platformer game
- AI WAS USED to debug the game (<10%)
- ad to move left, right, space to parry ( when u parry, u get boost. parrying here refers to timing the parry key just before u touch the ground) right click to groundpound.
- i made this game, because i wanted to learn how to make a platformer ( but i didnt have time to finish making it good :p).
- the spikes and the tilesets have been made by me, and the plr is from a dummy spritesheet which i edited.
- made in godot 4.7
